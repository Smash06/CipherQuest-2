Concept review

What each chamber teaches

01

Caesar Cipher

A substitution cipher shifts every letter by a fixed number. It demonstrates encryption, but is easy to break by trying all shifts.

02

Katapayadi

An Indian system that associates consonants with digits, historically helping encode and remember numbers. It is encoding, not secure encryption.

03

Bhuta Sankhya

A word-number system where familiar objects represent quantities, such as one moon or two eyes. It supports memorable numerical expression.

04

Steganography

The practice of hiding that a message exists. An acrostic can hide a word in initial letters, while modern methods can hide data in digital media.

Security note

These historical and classical techniques are excellent for learning, but they should not protect real passwords or sensitive data. Modern systems use reviewed algorithms such as AES with properly managed keys.

Technical architecture

Offline core, optional backend

The published game is intentionally static and offline-ready. The source package also includes an optional Node.js server that serves the game and accepts completed scores through a small REST API.

index.htmlStructure→styles.cssPresentation→game.jsGame logic→BrowserExecution

Backend scope: The included server stores scores temporarily in memory. A future version could connect it to MySQL or MongoDB for permanent accounts, leaderboards and saved progress.
